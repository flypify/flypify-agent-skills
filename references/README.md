# References

Drop your own files here and the agent can use them. Everything in this folder except this README is git-ignored, so it stays on your machine.

Useful things to keep here:

- `references/products/`: your own product photos (the statics skill picks the hero photo from these when you have better ones than the supplier's)
- `references/brand/`: logo, palette, fonts, brand voice notes
- `references/competitors/`: notes or screenshots from Brand Spy sessions (model the structure, never reuse another brand's photos or words)
- `references/winners/`: exported winner lists, so the weekly refresh can compare against last week

Tell the agent where a file is ("use the photos in references/products/"); it reads them before it briefs ads or pages.
